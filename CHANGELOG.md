# Changelog

Notable changes to HARMONY are recorded here. Version numbers follow semantic versioning.

## Unreleased

- Removed the hardcoded home-town default. Weather asks for a place when no home is saved.
- Added a private home-town setting with optional coordinates; weather uses it when no place is specified.
- Added Windows checks for installation, type checking, and tests on pushes and pull requests to `main`.

## 0.1.0 — 2026-10-27

- Published HARMONY as an open-source Windows desktop assistant under the MIT licence.
