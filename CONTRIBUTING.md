# Contributing

Thanks for looking. HARMONY started as one person's assistant for one PC, so expect rough edges.

- **Issues:** say what you did, what you expected and what happened, plus your Windows version, GPU and the relevant
  lines from `.runtime\startup.json` or the logs. Never paste keys, tokens or personal data.
- **Changes:** keep them small and focused, with a test. Run `npm run typecheck`, `npm test` and `npm run build`
  before opening a pull request. If you change anything the brain sees (instructions or functions), run
  `Check brain.cmd` and include the score.
- **Security problems:** please don't open a public issue; see `SECURITY.md`.
- **Style:** plain words in anything a person reads (messages, docs, comments). Measure before claiming something is
  faster.

By contributing you agree that your contribution is licensed under the MIT licence in `LICENSE`.
